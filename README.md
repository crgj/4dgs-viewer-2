# TrueSplats Viewer - 4D Gaussian Splatting Web Viewer

基于 **PlayCanvas** 和 **TypeScript** 构建的专业级 **4D Gaussian Splatting** 在线查看器，支持动态 4DGS 渲染、SOG4 / PLY4 导入导出、实时编辑、AR、相机预设、时间线控制和性能监控。

---

## ✨ 核心功能

### 🎬 4D 动态渲染
- **关键帧插值系统**
  - 位置 (XYZ) 关键帧线性插值
  - 旋转 (Quaternion) 球面线性插值 (SLERP)
  - 缩放 (Scale) 关键帧插值
  - 基于生命周期的透明度控制

- **实时播放控制**
  - 播放 / 暂停
  - 可拖拽时间轴
  - 多档 FPS 控制 (`12 / 24 / 30 / 60`)
  - 逐帧前进 / 后退
  - `A / B / Loop` 循环区间
  - 实时帧号显示

- **生命周期函数**
  - 基于双 Sigmoid 函数的平滑淡入淡出
  - 支持 `lifetime_mu` (中心时间) 和 `lifetime_w` (半宽) 参数

### 🎨 编辑与变换
- **多模式选择**
  - 笔刷模式
  - 矩形框选
  - 多边形框选
  - 反选 / 减选
  - 时间感知选择（当前帧可见点）
  - 全时段选择（所有帧可见点）

- **智能对齐与圆柱选择**
  - **Auto Align**：自动检测地面平面，计算旋转矩阵将场景归零（人物直立、地面水平）
  - **可调圆柱区域**：对齐后自动生成圆柱选择区，支持调整半径(R)、高度(H)、中心位置(X/Z)、地面余量(GROUND)
  - **全时段圆柱选择**：按圆柱区域在所有时间帧内检测点，支持 4D 轨迹插值和生命周期过滤
  - 输入框支持 **Scrub 拖拽** 微调数值

- **实时编辑**
  - 删除选中的高斯点
  - `Render ALL` 调试模式下可一键删除 normal 模式不可见但数据中仍存在的点
  - GPU 渲染结果即时更新
  - 编辑状态可写回导出文件

- **撤销 / 重做**
  - 支持最多 30 步删除操作撤销
  - `Ctrl+Z` 撤销
  - `Ctrl+Y` / `Ctrl+Shift+Z` 重做
  - 多段序列中每段选择状态独立保存，切段后自动恢复

- **模型变换**
  - 位置 / 旋转 / 缩放数值输入
  - Scrub 拖拽调整

### 📷 相机与标注
- **相机预设**
  - 保存当前相机位置与角度
  - 快速切换视角
  - 预设间平滑过渡

- **快捷视角**
  - Top / Front / Side

- **文本标注**
  - 2D 文字叠加
  - 字体、字号、颜色、粗体、斜体
  - 与相机预设绑定显示

### 📱 AR 与追踪
- **AR 模式**
  - 基于 MindAR 的图像跟踪
  - 摄像头设备选择
  - 6DoF 跟踪与坐标对齐

- **Face Tracking**
  - 摄像头驱动的视角偏移
  - 右下角视频预览

### 🎭 场景与视觉
- Grid / Axes 开关
- Gaussian Render 模式切换：`NORMAL / CENTER / OUTLINE / ALL`
- `ALL` 调试点云：无视生命周期和透明度显示未删除点，青色表示 normal 可见，粉色表示 normal 不可见
- 粒子过渡特效
- Dark / Light 主题切换
- Post Processing: Exposure / Brightness / Contrast

### 📈 Monitor 面板
- 实时 FPS / Frame Time / Splats
- FPS History
- Device Info
- Load Phases
- Warnings

### 💾 文件格式与导出
- **TrueSplats (.truesplats)**
- **SOG4 (.sog4)**
- **PLY4 (.ply4)**

- **导出**
  - `SOG4`: 保留项目内关键状态
  - `PLY4`: 导出当前模型数据
  - `PLY4 Sequence`: 多段序列导出（多段时自动显示）

- **批量转换**
  - 独立页面 `batch-convert.html`
  - 将多个 `.ply4` 批量转换为 `.sog4`
  - 将多帧 `.ply4` 逐帧导出为 PLY 序列；多个文件时合并为统一序列，按第一个文件名连续编号（打包为 zip）
  - 支持文件夹拖拽上传

- **SOG4 保存内容**
  - 模型整体位置 / 旋转 / 缩放
  - 相机预设
  - 文本标注
  - 后处理参数
  - 已删除点索引
  - 总帧数与相关时间元数据

## 📝 版本修改记录

### 2026-06-13

#### Render ALL 调试点云
- `RENDER` 面板新增 `ALL` 模式，使用独立 `DebugAllGaussianPoints` entity 绘制点云，不改主 GSplat shader。
- `ALL` 模式显示当前激活模型/段中所有未删除点，忽略生命周期和 opacity，便于检查数据中存在但 normal 模式不可见的点。
- 颜色约定：
  - 青色：normal 模式下预计可见的点。
  - 粉色：normal 模式下不可见但尚未删除的点。
  - 已删除点：不绘制。
- 进入 `ALL` 时自动切到左侧 `Edit` 面板，普通编辑按钮会禁用，仅 `Delete Hidden` 保持可用；切回 `NORMAL / CENTER / OUTLINE` 后恢复原 UI。
- `Delete Hidden` 会先弹出确认，再将当前帧 normal 不可见且尚未删除的点写入 deleted 标记；执行后 `ALL` 点云立即刷新，被删除点不再显示。
- 左侧工具区改为面板级两个 tab：`Smart` 放置自动对齐、统计和圆柱选择；`Edit` 放置选择、删除和隐藏点清理等操作。

### 2026-05-16 (v2.18.1)

#### Lazy 分段缓冲模式
- 当 PLY4 序列总体积超过 **4.0 GB** 时，自动切换为 **Lazy Segmented Buffering** 模式。
- **Full 模式**（&lt;4GB）：全序列一次性加载到 GPU，所有手工选择工具（笔刷/矩形/多边形）完全可用。
- **Lazy 模式**（&ge;4GB）：
  - 仅读取每段 header 建立完整时间轴，当前显示段才会解码并上传 GPU。
  - 手工区域/笔刷工具自动隐藏，保留反选、清空、删除操作；撤销 / 重做保留在顶部栏右侧。
  - 选择和删除状态按段保存，切换段时自动恢复。
  - 播放推进到未缓存段时自动暂停，右下角显示读取进度，加载完成后自动恢复。
- UI 右上角常驻标注当前模式：`PLY4 FULL`（绿色）或 `PLY4 LAZY`（青色）。
- 内存预检预算固定为 **10GB**，超出时弹出拦截提示。

#### Playbar & Timeline 多段序列指示
- 多段 PLY4/SOG4 序列播放时，**Playbar** 左上角显示当前段信息：
  - 格式：`SEG 2/5 · filename.ply4 · 12/299 · LAZY`
  - 包含：段编号/总段数 · 文件名 · 段内当前帧/段总帧 · 加载模式（FULL/LAZY）
  - 文件名过长时自动截断为 `前11...后12` 格式
  - 鼠标悬停可查看完整文件名、全局帧范围、缓存状态（READY/UNLOADED）
- **Timeline** 轨道上方用青色竖线和圆形数字标记每段起始边界：
  - 当前播放所在的段标记高亮为绿色（竖线加粗 + 发光阴影）
  - 单文件模式下段标记自动隐藏，保持界面简洁

#### 智能对齐（Auto Ground Alignment）
- 新增左侧 **Smart Selection Panel**，集成自动地面检测与场景对齐。
- 基于 **RANSAC + PCA** 的地面平面估计，结合动静点聚类识别人物主体。
- 自动计算旋转矩阵和平移向量，将场景归零：
  - 地面法向量对齐到世界 Y 轴
  - 人物中心对齐到原点
  - 场景缩放自动估计
- 算法在 **Web Worker** 中运行，避免阻塞主线程；失败时自动降级到主线程执行。
- 采样最多 30,000 个点进行分析，支持 4D 轨迹运动幅度估计。

#### 圆柱选择（Cylinder Selection）
- 对齐完成后自动生成可调圆柱区域，以**网格线框**在场景中可视化。
- 支持调整参数：
  - **R**（半径）- 圆柱水平范围
  - **H**（高度）- 圆柱顶部高度
  - **X / Z** - 圆柱中心水平位置
  - **GROUND** - 地面下方余量，防止漏选脚部点
- **Select In Cylinder** 按钮执行全时段选择：
  - 扫描所有 PLY4 序列段，逐段检测点是否在圆柱内。
  - 支持 4D 轨迹插值：按生命周期有效帧采样，轨迹经过圆柱即算命中。
  - 大文件扫描期间定期让出主线程，避免浏览器卡死。
  - 当前帧可见点写入高亮通道，全时段命中点写入 all-time 通道。
- 关闭圆柱时可选择是否清空当前选区。

#### 选择系统增强
- **all-time 选择通道分离**：当前帧高亮通道（R）与全时段操作通道（all-time）独立存储。
  - 避免当前帧显示大量圆柱外点。
  - 反选时以 all-time 通道为基准，保证圆柱选择后的反选逻辑正确。
- **多段序列选择状态持久化**：
  - 每段拥有独立的 `selectionData` / `allTimeSelectionData` / `selectionTexture`。
  - 切换段前自动保存当前段编辑状态，切换后自动恢复。
  - Lazy 模式下卸载段时状态写入 `sequenceEditStates`，重新加载时还原。
- **Undo/Redo 支持跨段**：捕获快照时保存所有段的选择状态，恢复时同步还原视图上下文（段索引/时间）。

#### 输入交互增强
- 所有数值输入框（位置、旋转、缩放、圆柱参数）统一支持 **Scrub 拖拽**：
  - 按住鼠标左右拖动即可微调数值，无需手动输入。
  - 旋转步进 1°，位置步进 0.05，缩放步进 0.02，圆柱参数步进 0.01。

### 2026-04-19 (v2.16)

#### 批量转换工具
- 新增独立的 `batch-convert.html` 批量转换页面。
- 支持拖拽上传多个 `.ply4` 文件或整个文件夹。
- 队列管理，显示每个任务的 Prepare / Load PLY4 / Encode SOG4 / Download 四阶段进度。
- 支持两种导出格式切换（默认 SOG4）：
  - **SOG4**：将 `.ply4` 编码为压缩的 `.sog4`，保留模型变换信息。
  - **PLY 序列**：将多帧 `.ply4` 逐帧插值导出为单帧 `.ply4`；拖入多个文件时合并为统一序列，所有帧按第一个文件名连续编号（`name_000.ply4`, `name_001.ply4`…），打包为 zip 下载。
- 支持自动下载转换完成的文件。
- 任务失败后可单独重试。

#### WebP 无损纹理编码
- 引入 `@jsquash/webp` 编码器，SOG4 纹理数据改用无损 WebP 压缩。
- 相比原有 canvas blob 导出，显著减小 SOG4 文件体积。
- 编码器同时应用于标准模式和快速模式。

#### 模型变换系统重构
- 新增 `src/utils/model-transform.ts`，统一模型变换类型与读写逻辑。
- SOG4 编码器现在将 `model_pos` / `model_rot` / `model_scale` 写入 `meta.json`。
- 修复 `.sog4` 保存后再次读取时模型整体变换未正确恢复的问题。
- 导出时智能选择变换策略：若模型未被编辑则保留原始变换，否则使用当前编辑状态。

#### 全时段选择工具 (All-Time Selection)
- 左侧选择面板顶部提供 `Current / All-Time` 范围切换。
- 切到 `All-Time` 后，笔刷 (`1`)、矩形 (`2`) 和多边形 (`3`) 会以全时间范围执行选择。
- 可选中所有时间帧内可见的高斯点，而不仅限于当前帧。
- 反选操作同样支持全时段范围。
- 笔刷路径采用简化算法，优化大规模全时段选择的性能。

#### PLY4 加载进度细化
- `PLY4Loader` 新增 `PLY4LoadProgressMeta` 类型。
- 加载过程拆分为 Header / Body / Finalize 阶段，支持子步骤和 chunk 级进度追踪。
- 为批量转换等场景提供更精细的进度反馈。

## 🎮 使用指南

### 加载模型
- 拖拽 `.truesplats`、`.sog4`、`.ply4` 到画布
- 点击右上角 `Open`
- 使用左上角 `Samples`
- 多段序列：同时拖拽多个 `.sog4` 或 `.ply4` 文件，自动按文件名数字排序

### 基本操作

| 操作 | 方式 |
|------|------|
| 旋转视角 | 左键拖拽 |
| 平移视角 | 右键拖拽 |
| 缩放视角 | 鼠标滚轮 |
| 播放 / 暂停 | 空格键或播放按钮 |
| 逐帧后退 / 前进 | `← / →` 或时间线步进按钮 |
| 隐藏 / 显示 UI | `H` 或双击画布 |

### 选择与编辑

| 快捷键 | 功能 |
|--------|------|
| `1` | 切换笔刷工具 |
| `2` | 切换矩形工具 |
| `3` | 切换多边形工具 |
| `Alt` + 拖拽 | 减选模式 |
| `Delete` | 删除当前选中点 |
| `Ctrl+Z` | 撤销 |
| `Ctrl+Y` | 重做 |
| `Ctrl+Shift+Z` | 重做 |
| `Esc` | 退出当前选择工具 |

#### 左侧选择栏布局
- 顶部 `Current / All-Time` 是范围切换，不再为全时段单独提供一套工具按钮。
- 中部按顺序分为 `Tools`、`Hit Mode` 和 `Edit` 三组。
- `Edit` 组集中放置反选、清空和删除；删除前的撤销 / 重做按钮移动到顶部品牌栏右侧。
- 左侧工具区顶部提供面板级 `Smart / Edit` 两个 tab：`Smart` 集中自动对齐、统计和圆柱选择；`Edit` 放置普通选择、删除和 `Delete Hidden` 等操作。

#### 时间感知选择
- 播放动画时，只选择当前时刻可见的点
- 静止时，只选择当前帧可见的点
- 可见性由生命周期参数控制

#### 全时段选择
- 在左侧工具栏顶部切换至 **All-Time** 模式后，笔刷 (`1`)、矩形 (`2`) 和多边形 (`3`) 工具可选中所有时间帧内可见的高斯点
- 不受当前播放进度限制，适合清理跨帧存在的噪点
- 反选操作同样作用于全时段范围

#### Render ALL 与隐藏点清理
- 右侧 `RENDER` 面板的 `ALL` 按钮会切换到独立调试点云，不使用 normal 的生命周期和透明度过滤。
- `ALL` 只绘制未删除点：青色表示 normal 下可见，粉色表示 normal 下不可见。
- 切到左侧工具区的 `Edit` tab，点击 `Delete Hidden` 后会确认删除当前帧 normal 不可见且尚未删除的点；确认后这些点会写入 deleted 标记，导出时也会被过滤。
- 在 `ALL` 模式下会自动切到 `Edit` tab，普通编辑按钮禁用，仅 `Delete Hidden` 按钮保持可用。
- 删除后 `ALL` 点云会立即刷新，已删除点不再显示。

## 🧠 技术原理

### 4D 生命周期函数

使用双 Sigmoid 函数实现高斯点的平滑淡入淡出：

$$
M(t) = \sigma(k \cdot (t - (\mu_t - w_t))) \cdot \sigma(-k \cdot (t - (\mu_t + w_t)))
$$

其中：
- $\mu_t$：生命周期中心时间
- $w_t$：生命周期半宽
- $k = 10.0$：衰减敏锐度
- $\sigma(x) = \frac{1}{1 + e^{-x}}$

### 关键帧插值
- **位置**: 线性插值 (LERP)
- **旋转**: 球面线性插值 (SLERP)
- **缩放**: 线性插值
- **不透明度**: 生命周期函数调制

着色器在 GPU 端实时计算，浏览器端驱动时间轴、循环区间和逐帧步进。

### AR 坐标对齐
1. 实时检测标记位置和姿态
2. 计算 4x4 变换矩阵
3. 将 PlayCanvas 世界坐标系对齐到标记中心
4. 应用后处理矩阵修正旋转和平移

### 智能对齐算法
1. **采样**：从 4DGS 点云中均匀采样最多 30,000 个点
2. **运动估计**：利用轨迹数据计算每点的最大运动幅度，区分动态/静态点
3. **聚类**：对静态点进行 DBSCAN 聚类，找出地面候选簇
4. **平面拟合**：使用 RANSAC 在最大静态簇上拟合地面平面
5. **人物检测**：对动态点聚类，找出人物主体簇
6. **变换计算**：通过 PCA 计算旋转矩阵，使地面法向量对齐 Y 轴；计算平移使人物中心位于原点
7. **圆柱生成**：根据人物簇的包围盒自动生成初始圆柱参数

## 📄 文件格式

### TrueSplats (.truesplats)
- 专有 4DGS 二进制格式
- 包含静态属性、动态轨迹和扩展元数据

### SOG4 (.sog4)
- 当前项目的压缩交换格式
- 支持导入 / 导出
- 保留编辑状态与项目元数据

### PLY4 (.ply4)
- 用于点云 / 4D 数据交换
- 支持当前模型数据导出
- 支持多段序列（Lazy / Full 两种加载模式）
