# TrueSplats Viewer - 4D Gaussian Splatting Web Viewer

基于 **PlayCanvas** 和 **TypeScript** 构建的专业级 **4D Gaussian Splatting** 在线查看器，支持动态 4DGS 渲染、SOG4 / PLY4 导入导出、实时编辑、AR、相机预设、时间线控制和性能监控。

---

## ✨ 核心功能

### 🎬 4D 动态渲染
- **关键帧插值系统**
  - 位置 (XYZ) 关键帧线性插值
  - 旋转 (Quaternion) 球面线性插值 (SLERP)
  - 缩放 (Scale) 关键帧插值
  - 基于生命周期的透明度控制

- **实时播放控制**
  - 播放 / 暂停
  - 可拖拽时间轴
  - 多档 FPS 控制 (`12 / 24 / 30 / 60`)
  - 逐帧前进 / 后退
  - `A / B / Loop` 循环区间
  - 实时帧号显示

- **生命周期函数**
  - 基于双 Sigmoid 函数的平滑淡入淡出
  - 支持 `lifetime_mu` (中心时间) 和 `lifetime_w` (半宽) 参数

### 🎨 编辑与变换
- **多模式选择**
  - 笔刷模式
  - 矩形框选
  - 反选 / 减选
  - 时间感知选择

- **实时编辑**
  - 删除选中的高斯点
  - GPU 渲染结果即时更新
  - 编辑状态可写回导出文件

- **撤销 / 重做**
  - 支持最多 30 步删除操作撤销
  - `Ctrl+Z` 撤销
  - `Ctrl+Y` / `Ctrl+Shift+Z` 重做

- **模型变换**
  - 位置 / 旋转 / 缩放数值输入
  - Scrub 拖拽调整

### 📷 相机与标注
- **相机预设**
  - 保存当前相机位置与角度
  - 快速切换视角
  - 预设间平滑过渡

- **快捷视角**
  - Top / Front / Side

- **文本标注**
  - 2D 文字叠加
  - 字体、字号、颜色、粗体、斜体
  - 与相机预设绑定显示

### 📱 AR 与追踪
- **AR 模式**
  - 基于 MindAR 的图像跟踪
  - 摄像头设备选择
  - 6DoF 跟踪与坐标对齐

- **Face Tracking**
  - 摄像头驱动的视角偏移
  - 右下角视频预览

### 🎭 场景与视觉
- Grid / Axes 开关
- Gaussian Render 模式切换
- 粒子过渡特效
- Dark / Light 主题切换
- Post Processing: Exposure / Brightness / Contrast

### 📈 Monitor 面板
- 实时 FPS / Frame Time / Splats
- FPS History
- Device Info
- Load Phases
- Warnings

### 💾 文件格式与导出
- **TrueSplats (.truesplats)**
- **SOG4 (.sog4)**
- **PLY4 (.ply4)**

- **导出**
  - `SOG4`: 保留项目内关键状态
  - `PLY4`: 导出当前模型数据

- **SOG4 保存内容**
  - 模型整体位置 / 旋转 / 缩放
  - 相机预设
  - 文本标注
  - 后处理参数
  - 已删除点索引
  - 总帧数与相关时间元数据

## 🎮 使用指南

### 加载模型
- 拖拽 `.truesplats`、`.sog4`、`.ply4` 到画布
- 点击右上角 `Open`
- 使用左上角 `Samples`

### 基本操作

| 操作 | 方式 |
|------|------|
| 旋转视角 | 左键拖拽 |
| 平移视角 | 右键拖拽 |
| 缩放视角 | 鼠标滚轮 |
| 播放 / 暂停 | 空格键或播放按钮 |
| 逐帧后退 / 前进 | `← / →` 或时间线步进按钮 |
| 隐藏 / 显示 UI | `H` 或双击画布 |

### 选择与编辑

| 快捷键 | 功能 |
|--------|------|
| `1` | 切换笔刷工具 |
| `2` | 切换矩形工具 |
| `Alt` + 拖拽 | 减选模式 |
| `Delete` | 删除当前选中点 |
| `Ctrl+Z` | 撤销 |
| `Ctrl+Y` | 重做 |
| `Ctrl+Shift+Z` | 重做 |
| `Esc` | 退出当前选择工具 |

#### 时间感知选择
- 播放动画时，只选择当前时刻可见的点
- 静止时，只选择当前帧可见的点
- 可见性由生命周期参数控制

### 时间线
- 拖动时间轴可直接跳转到目标帧
- 点击 `A` 将当前帧设为循环起点
- 点击 `B` 将当前帧设为循环终点
- 点击 `Loop` 开启 / 关闭区间循环
- 推荐顺序是先移动到起始帧后点 `A`，再移动到结束帧后点 `B`，最后点 `Loop`
- 如果重新设置了 `A` 或 `B`，循环范围会立即按新的区间更新
- 点击左右逐帧按钮可逐帧检查动画

### AR 模式
1. 打印 `public/marker/` 里的标记
2. 在 `SPECIAL` 面板选择摄像头
3. 点击 `AR` 按钮启动
4. 将标记对准摄像头

### 导出
- 点击 `SOG4` 导出完整项目状态
- 点击 `PLY4` 导出当前模型数据

## 🧠 技术原理

### 4D 生命周期函数

使用双 Sigmoid 函数实现高斯点的平滑淡入淡出：

$$
M(t) = \sigma(k \cdot (t - (\mu_t - w_t))) \cdot \sigma(-k \cdot (t - (\mu_t + w_t)))
$$

其中：
- $\mu_t$：生命周期中心时间
- $w_t$：生命周期半宽
- $k = 10.0$：衰减敏锐度
- $\sigma(x) = \frac{1}{1 + e^{-x}}$

### 关键帧插值
- **位置**: 线性插值 (LERP)
- **旋转**: 球面线性插值 (SLERP)
- **缩放**: 线性插值
- **不透明度**: 生命周期函数调制

着色器在 GPU 端实时计算，浏览器端驱动时间轴、循环区间和逐帧步进。

### AR 坐标对齐
1. 实时检测标记位置和姿态
2. 计算 4x4 变换矩阵
3. 将 PlayCanvas 世界坐标系对齐到标记中心
4. 应用后处理矩阵修正旋转和平移

## 📄 文件格式

### TrueSplats (.truesplats)
- 专有 4DGS 二进制格式
- 包含静态属性、动态轨迹和扩展元数据

### SOG4 (.sog4)
- 当前项目的压缩交换格式
- 支持导入 / 导出
- 保留编辑状态与项目元数据

### PLY4 (.ply4)
- 用于点云 / 4D 数据交换
- 支持当前模型数据导出
